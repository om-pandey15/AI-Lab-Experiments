# AI Lab Experiments

Learning Artificial Intelligence one algorithm at a time.

## About This Repository

This repository contains 11 AI lab experiments implemented in Python. Each experiment helps me understand a different approach to search, decision-making, and problem-solving.

I also built an [A* Path-Finding Visualizer](https://github.com/om-pandey15/A-Path-Finding-Visualizer) using Python and Pygame to explore pathfinding through an interactive grid.

## Experiments

1. BFS Search
2. BFS Traversal
3. DFS Search
4. Hill Climbing
5. A* Search
6. Min-Max
7. Alpha-Beta Pruning
8. 8-Queens Problem
9. Water Jug Problem
10. Travelling Salesman Problem
11. Tic-Tac-Toe
